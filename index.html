Three Levels, One Idea

✦

The Throughline

One locked sentence — the argument the whole presentation makes. Write it early as a hypothesis, refine it as you build. When you're done, it should be the thing a room member could repeat back the next day.

≡

Nodes, Not Slides

Each node is one point — written as a complete sentence. Not a topic, not a category. "Our close rate dropped 18% after we changed the proposal format" is a node. A title is a label, not a node.

→

Dump. Sort. Sharpen.

Start by generating without worrying about order. Then group, collapse, and find the gaps. Then rewrite every node title as a clear sentence — if you can't write the point as a sentence, you don't know the point yet.
